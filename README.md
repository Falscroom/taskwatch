# taskwatch — монитор тасок и MR в строке меню macOS

Показывает карточки: твои MR из GitLab (упавшие сборки, конфликты, «изменения запрошены»),
таски YouTrack спринта, MR, где ты ревьюер. Уведомляет о новых событиях один раз.

## Установка

Нужен Mac на **Apple Silicon** с macOS 14+.

1. Распакуй архив в любую папку.
2. Открой Терминал в этой папке (правый клик по папке → «Новый терминал по адресу»).
3. `./install.sh`

Установка разворачивается в фиксированную папку `~/.local/share/taskwatch` внутри твоей
домашней директории — карантин Gatekeeper скрипт снимает **только** с файлов приложения
там, папку с архивом не трогает. Обновление: распакуй новый архив и снова запусти
`./install.sh` из него.

Иконка появится в строке меню через пару секунд и будет стартовать сама при входе в систему.
Если при первом запуске macOS заругалась на «непроверенного разработчика» — скрипт это
предотвращает, но если что: `xattr -dr com.apple.quarantine ~/.local/share/taskwatch`.

## Настройка

Клик по иконке → шестерёнка справа вверху:

- **GitLab** (достаточно его одного, чтобы уже работало): URL типа `https://gitlab.example.com`,
  логин, personal access token с правом `read_api` (GitLab → Settings → Access Tokens).
- **YouTrack** (опционально): URL, permanent token (`perm:...`), логин, запрос тасок спринта
  вроде `for: me Sprint: {Current sprint}`.
- Правила: сколько апрувов нужно для перевода, статус ревью, команда перевода.
  Порог «MR отстал от target на N коммитов» — такой MR попадает в «требуют работы»
  с бейджем «Отстаёт на N коммитов» (0 — не подсвечивать).

Кнопка «Проверить» покажет, что связь работает. «Сохранить» — всё, конфиг перечитается на лету.

Конфиг лежит в `~/.config/taskwatch/config.yaml` (права 0600) — в нём только настройки:
URL-ы, логины, правила. **Токены macOS хранит в Связке ключей** (искать «com.taskwatch»),
на диск в открытом виде они не попадают.

## Что на иконке

Цифра = число карточек, требующих твоего действия: твой MR сломался / ждёт твоего ревью /
апрувы собраны и пора переводить таску.

## Действия на карточке

- **🔕 Заглушить** — карточка спрячется во вкладку «Все → Заглушено», уведомления по ней
  прекратятся (на час / 3 часа / сутки / навсегда). Галочка «заглушить все карточки с таким же
  названием» глушит всю группу разом — и будущие MR с этим названием тоже. Вернуть — 🔔
  на любой карточке группы.
- **Исключать draft** (галочка в настройках) — draft-MR не показываются и не шумят, пока автор
  не снимет черновик.

## Удаление

`./uninstall.sh` из папки с архивом (или остановить руками:
`launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/com.taskwatch.plist`).
Скрипт заодно удаляет токены из Связки ключей. Конфиг с настройками останется
в `~/.config/taskwatch` — удалить руками, если нужно.

## Если что-то не так

Лог: `~/.config/taskwatch/taskwatch.log`. Перезапуск: `launchctl kickstart -k gui/$(id -u)/com.taskwatch`.
После обновления версии macOS может один раз спросить доступ к Связке ключей — это нормально,
нажми «Разрешить».

## Исходники

Папка `src/` — весь код на Go (собирается `make build`, нужен Go 1.2x и Xcode CLT).
Конфиг для примера — `src/config.example.yaml`.
